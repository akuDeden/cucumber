# at-need Snapshots

Form At-need Plot Purchase — multi-step form untuk pembelian plot (walk-in / emergency).

| File | Step Form | Keterangan |
|------|-----------|------------|
| `at-need-initial.yml` | Step awal | Form baru dibuka, semua field kosong |
| `at-need-deceased.yml` | Deceased details | Setelah isi data almarhum |
| `at-need-after-applicant.yml` | Applicant details | Setelah isi data pemohon/applicant |
| `at-need-roi-applicant.yml` | ROI + Applicant | Setelah pilih ROI dan isi applicant |
| `at-need-event-service.yml` | Event & service | Step event/service details |
| `at-need-form.yml` | Form umum | Snapshot generik form At-need |

**Entry point**: Dashboard > Request > At-need Plot Purchase
