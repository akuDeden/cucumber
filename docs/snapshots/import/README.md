# import Snapshots

Halaman Import data — upload CSV/GeoJSON ke Chronicle.

| File | State | Keterangan |
|------|-------|------------|
| `import-page.yml` | Awal | Import page baru dibuka (lihat README header di file) |
| `import-page-empty.yml` | Empty | Import page tanpa file terupload |
| `import-page-files-uploaded.yml` | Files ready | Import page setelah file dipilih, siap di-import |
| `import-wipe-dialog.yml` | Wipe dialog | Dialog konfirmasi "Wipe data" muncul |

**Entry point**: Dashboard > More menu > Import
